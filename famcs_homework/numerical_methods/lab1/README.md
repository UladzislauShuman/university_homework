# команды
прежде чем выполнять команду, вы должны быть в коренвой папке программы (то есть в lab1/)
- `python lab1.py <название_файла_которого_не_существует>.txt random <натуральное число, размер матрицы>`
- `python lab1.py <название файла, который есть>.txt`
- `python test.py <начальный размер матрицы> <коненчый размер> <шаг>`
