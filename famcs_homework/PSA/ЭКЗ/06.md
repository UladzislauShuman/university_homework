### Вопрос 6: Классификация, деревья решений

**1. Введение и основные понятия**
**Классификация** — это задача интеллектуального анализа данных (ИАД), суть которой заключается в отнесении объекта к одному из заранее известных классов на основе его характеристик (признаков).

**Деревья решений (Decision Trees)** — это метод автоматической классификации, представляющий собой логическую схему принятия решений в виде ориентированного ациклического графа (дерева). 
Дерево состоит из:
*   **Корневого узла (root node):** содержит всю обучающую выборку, здесь задается первый вопрос.
*   **Внутренних узлов (internal nodes):** представляют собой проверки (предикаты) по определенному признаку.
*   **Ветвей (branches):** варианты ответов на проверку, по которым осуществляется переход к следующему уровню.
*   **Листьев (leaf nodes / концевых вершин):** конечные узлы, которым присвоена метка конкретного класса.

**2. Принцип построения (Обучение дерева)**
В основе построения лежит принцип **«разделяй и властвуй» (рекурсивное разбиение)**. 
На каждом шаге алгоритм ищет такой признак $X_j$ и такое правило (предикат), которое наилучшим образом разделит текущее множество объектов на максимально однородные (по целевому классу) подмножества. 
*   Для непрерывного признака предикат имеет вид $X_j \ge \delta$ (где $\delta$ — пороговое значение).
*   Для категориального признака проверяется принадлежность к определенному подмножеству значений.

**3. Критерии качества разбиения (Меры неоднородности)**
Чтобы выбрать наилучший признак для ветвления, алгоритм должен оценить «чистоту» (однородность) получаемых узлов. Для этого используются следующие математические функции:

**А) Информационная энтропия (Мера неопределенности)**
Показывает степень хаоса в узле. Чем ниже энтропия, тем однороднее узел.
$$ E(t) = - \sum_{j=1}^{m} p(j|t) \log_2 p(j|t) $$
*(Примечание: в некоторых источниках, например в лекциях Сенько, используется натуральный логарифм $\ln$, но суть остается той же).*
*Где:*
*   $t$ — текущий рассматриваемый узел дерева;
*   $m$ — общее количество классов в задаче;
*   $p(j|t)$ — относительная частота (доля) объектов класса $C_j$ в узле $t$.
*Свойство:* $E(t) = 0$, если все объекты в узле принадлежат к одному классу (идеальная ситуация). Максимум достигается при равномерном распределении объектов по всем классам.

**Б) Индекс Джини (Gini Impurity)**
Альтернативный показатель однородности группы.
$$ G(t) = 1 - \sum_{j=1}^{m} [p(j|t)]^2 $$
*Где переменные те же:* $p(j|t)$ — доля объектов $j$-го класса в узле $t$. Чем ниже индекс Джини, тем лучше разбиение.

**В) Ошибка классификации**
$$ Er(t) = 1 - \max_j p(j|t) $$
Показывает долю объектов, которые будут классифицированы неверно, если узлу $t$ присвоить метку мажоритарного (самого частого) класса.

**4. Выбор оптимального признака (Прирост информации)**
Алгоритм (например, ID3) выбирает для разбиения тот признак, который дает максимальный **прирост информации (Information Gain)** — то есть максимально снижает энтропию системы после разбиения:
$$ GI_s(t) = E(t) - \sum_{i=1}^{k} \frac{M_{t_i}}{M_t} E(t_i) $$
*Где:*
*   $GI_s(t)$ — прирост информации при разбиении узла $t$ по выбранному признаку;
*   $E(t)$ — энтропия родительского узла $t$ (до разбиения);
*   $k$ — количество узлов-потомков, на которые разбивается узел $t$;
*   $M_t$ — общее число объектов в родительском узле $t$;
*   $M_{t_i}$ — число объектов, попавших в $i$-й узел-потомок $t_i$;
*   $E(t_i)$ — энтропия $i$-го узла-потомка.

**5. Остановка построения и проблема переобучения**
Если строить дерево до тех пор, пока в каждом листе не останутся объекты только одного класса, дерево получится огромным и **переобученным (overfitted)**. Оно идеально запомнит обучающую выборку, но будет давать плохие прогнозы на новых данных.

Для борьбы с этим применяют:
1.  **Раннюю остановку (Pre-pruning):** Задаются ограничения до начала построения (максимальная глубина дерева, минимальное число объектов в листе, остановка, если прирост информации $GI_s(t)$ меньше заданного порога).
2.  **Отсечение ветвей (Post-pruning / Подрезка):** Сначала строится полное дерево, а затем наименее информативные ветви удаляются (заменяются листом с мажоритарным классом). Качество подрезки проверяется на отдельной *контрольной (тестовой) выборке*.

**6. Основные алгоритмы деревьев решений**
*   **ID3 (Iterative Dichotomiser 3):** Базовый алгоритм. Использует энтропию и прирост информации. Работает только с категориальными признаками. Склонен к переобучению.
*   **C4.5:** Улучшенная версия ID3. Умеет работать с непрерывными (числовыми) признаками (динамически ищет пороги разбиения), использует нормализованный прирост информации (Gain Ratio) и поддерживает процедуру подрезки (pruning).
*   **CART (Classification and Regression Trees):** Строит строго *бинарные* деревья (каждый узел делится ровно на 2 ветви). Для задач классификации использует индекс Джини.

**7. Извлечение правил**
После построения дерева любой путь от корня к листу можно легко преобразовать в логическое правило вида: `ЕСЛИ (Условие 1) И (Условие 2) ТО (Класс Y)`. Это делает деревья решений одним из самых интерпретируемых (понятных человеку) методов машинного обучения.
